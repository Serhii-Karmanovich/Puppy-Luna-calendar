# Межі безпеки проєкту

Ці правила діють для роботи над `Puppy-Luna-calendar`.

- Працювати лише з файлами цього проєкту та його репозиторієм GitHub.
- Не читати, не змінювати й не завантажувати інші файли.
- Не видаляти дані та не виконувати незворотні дії без окремого дозволу.
- Не змінювати налаштування комп’ютера або браузера, крім конкретного дозволу, необхідного для завантаження файлів у GitHub.
- Не надсилати повідомлення, не купувати послуги та не підключати сторонні сервіси без окремого дозволу.
- Не використовувати й не передавати паролі, `service_role key`, токени або інші секрети.
- Змінювати лише код застосунку, схему Supabase та налаштування, необхідні для цього проєкту.
- Будь-яка дія поза межами проєкту потребує окремого дозволу користувача.

Після завантаження файлів дозвіл Chrome «Надавати доступ до URL-адрес файлу» слід вимкнути.
